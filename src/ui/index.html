Proxy

Each tab takes the next proxy in order. Start a line with a region code (us, ca…) to make it selectable by region. The check queries ipquery.io through every proxy and drops anything flagged as datacenter, VPN, TOR, known-proxy, risk ≥ 70, or unreachable.

{session} becomes a random id per tab (its sticky IP); Burn IP draws a new one. Add {country} to the template to switch regions per tab, e.g. user-country-{country}-session-{session}.

The endpoint must return one HTTP or SOCKS5 proxy per line, in the same format as a proxy list.

    Password sync & OTP

    Fetch the password from an API on each autofill, and the latest OTP from a service like TextChest. Each URL may use its own Authorization header; both are encrypted alongside the profile.

    The key fetches SMS via GET api.textchest.com/sms?number=…. Needs the profile's SMS Number set too. (For a custom OTP endpoint not TextChest, use the two fields below instead.)

    One site per line. Leave the :KEY part off a resolver (e.g. smscode=textchest) to keep the key you already saved.

    Cards

      Passwords, card numbers and CVVs are encrypted with your system keychain and never shown again — replace or remove them instead.
