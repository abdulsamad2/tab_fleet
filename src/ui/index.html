TabFleet

Open a fleet of tabs, each with its own session and IP.

Start
Proxy

Each tab takes the next proxy in order. Start a line with a region code (us, ca…) to make it selectable by region.

{session} becomes a random id per tab (its sticky IP); Burn IP draws a new one. Add {country} to the template to switch regions per tab, e.g. user-country-{country}-session-{session}.

The endpoint must return one HTTP or SOCKS5 proxy per line, in the same format as a proxy list.
