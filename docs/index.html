Built around isolated sessions

Everything in TabFleet starts from one idea: a tab is a separate identity.

🧩

A session per tab

Each tab gets its own cookies, local storage, cache and logins. Sign in to the same site with a different account in every tab — they never see each other.

🌐

An IP per tab

Every tab connects through its own proxy, so each session has its own IP address. Tabs can also start on your normal connection.

🔥

New IP, same login

Swap a profile tab to a fresh IP in one click and stay signed in. On a plain tab, New IP starts a clean session on the next IP and reloads the same page.

↔️

Proxy ↔ local IP, live

Move a tab between your own connection and a proxy without reloading the page or losing its session — handy for steps that need your home IP.

🗺️

Pick a region per tab

Tag proxies or use a gateway with a {country} placeholder, then choose US, CA, GB… for each tab from the toolbar.

👤

Profiles keep their session

Each saved profile owns a persistent session and its own proxy. Its cookies and logins survive restarts, and every tab you open with it shares them.

🪟

Pop-ups stay put

Windows a site opens — sign-in pop-ups, payment pages — stay in the tab's session and IP, so nothing leaks into another identity.

📑

Duplicate into a fresh session

Duplicate a tab to get the same page in a brand-new session (or the same profile's session), ready for another account.

🧹

Private by default

Plain tab sessions live in memory and vanish when you quit. Profile sessions are kept; clear any profile's cookies with one click.

How it works

  1. 1

    Choose your fleet

    Pick a start page, how many tabs to open (up to 50), and whether each tab gets its own session or they all share one.

  2. 2

    Plug in your IPs

    Paste a proxy list, point at a rotating gateway, or load a list from a URL. Or start on your local IP and switch tabs to a proxy only when you need to.

  3. 3

    Launch

    Every tab opens isolated, on its own IP. Assign saved profiles to tabs and they move into that profile's session, logins and proxy included.

  4. 4

    Swap IPs on the fly

    Hit New IP on one tab or every tab, switch regions, or flip a tab to your local IP — without losing the session you're in.

Bring any proxy

Proxy list

One proxy per line. Each tab takes the next one; add a region code to make it selectable.

host:port
host:port:user:pass
user:pass@host:port
http://host:port
socks5://host:port
us host:port:user:pass

Rotating gateway

{session} becomes a sticky id per tab — New IP draws another. {country} follows the tab's region.

Host      gate.provider.com
Port      7000
Username  user-country-{country}-session-{session}
Regions   us, ca, gb

Remote list

Point TabFleet at a URL that returns a proxy list (with an optional Bearer token) and it loads the list at launch.

https://provider.example/proxies.txt

HTTP and HTTPS proxies support usernames and passwords. SOCKS5 proxies work without authentication (a Chromium limitation).

FAQ

Is a tab really isolated from the others?

Yes. Each tab (or each profile) runs in its own Chromium session partition: separate cookies, local storage, IndexedDB, cache and service workers, plus its own proxy. A site can't read another tab's session.

Do I lose my login when I change a tab's IP?

Not on profile tabs, or when you switch between proxy and local IP — the session stays and only the IP changes. On a plain tab, New IP intentionally starts a clean session on the new IP.

What happens to sessions when I quit?

Plain tab sessions are kept in memory and disappear when you quit. Profile sessions are saved, so a profile is still signed in next time.

Can several tabs share one identity?

Yes — open them with the same profile, or launch in shared-session mode where every tab uses one session.

Do I need proxies?

No. Without proxies, tabs still get separate sessions on your own IP. Proxies add a separate IP per tab.

How do updates work?

On Windows, TabFleet checks for updates on launch and every two hours, downloads them in the background and installs on restart — notifications and automatic downloads can be turned off in Settings. On macOS, download new versions from this page until the Mac build is signed.
